# DataVista Pro - 技术架构文档

## 1. 架构设计原则

### 1.1 核心规范遵循
本项目严格遵循 **AI可强制执行·严格二叉树层级模块化工程刚性规范 V2.0**

所有设计决策必须满足四大顶层不变公理：
1. **模块结构公理**：所有非叶子模块直属子模块数量严格等于2
2. **调用隔离公理**：跨模块仅可引用Interface接口
3. **文件命名公理**：文件名单词数量严格等于所在模块层级
4. **方法行数公理**：所有方法有效代码行严格≤10行

### 1.2 技术栈
- **后端**：Python 3.10+ / FastAPI / Pandas / NumPy
- **前端**：HTML5 / CSS3 / JavaScript ES6+ / Chart.js / ECharts
- **通信**：RESTful API / JSON

### 2.2 模块职责定义

#### Level 1 模块

**DataCore（数据核心模块）**
- 职责：负责所有数据定义、数据处理、数据管理
- 约束：固定2个Level 2子模块

**ViewCore（视图核心模块）**
- 职责：负责所有图表渲染、仪表盘布局、界面展示
- 约束：固定2个Level 2子模块

#### Level 2 叶子模块

**DataDefine（数据定义模块）**
- 职责：指标定义、指标类型、指标配置
- 接口：IIndicatorDefine、IndicatorTypeEnum

**DataProcess（数据处理模块）**
- 职责：数据清洗、数据转换、数据聚合
- 接口：IDataProcess、DataFormatEnum

**ViewChart（图表视图模块）**
- 职责：图表渲染配置、图表类型管理、图表交互
- 接口：IChartRender、ChartTypeEnum

**ViewDashboard（仪表盘视图模块）**
- 职责：仪表盘布局、组件管理、布局配置
- 接口：IDashboardLayout、LayoutTypeEnum

## 3. 接口契约设计

### 3.1 DataDefine模块接口

#### IIndicatorDefine
```python
class IIndicatorDefine(ABC):
    @abstractmethod
    def create_indicator(self, name: str, indicator_type: str, config: Dict) -> str:
        pass

    @abstractmethod
    def update_indicator(self, indicator_id: str, updates: Dict) -> bool:
        pass

    @abstractmethod
    def delete_indicator(self, indicator_id: str) -> bool:
        pass

    @abstractmethod
    def get_indicator(self, indicator_id: str) -> Optional[Dict]:
        pass

    @abstractmethod
    def list_indicators(self, filters: Optional[Dict]) -> List[Dict]:
        pass
```

### 3.2 DataProcess模块接口

#### IDataProcess
```python
class IDataProcess(ABC):
    @abstractmethod
    def process_data(self, data: List[Dict], process_type: str) -> List[Dict]:
        pass

    @abstractmethod
    def aggregate_data(self, data: List[Dict], group_by: List[str]) -> Dict:
        pass

    @abstractmethod
    def transform_data(self, data: List[Dict], transforms: List[str]) -> List[Dict]:
        pass

    @abstractmethod
    def validate_data(self, data: List[Dict], rules: Dict) -> ValidationResult:
        pass
```

### 3.3 ViewChart模块接口

#### IChartRender
```python
class IChartRender(ABC):

    @abstractmethod

        pass
```

## 7. API接口设计

### 7.1 RESTful API端点

#### 指标管理
- `POST /api/indicators` - 创建指标
- `GET /api/indicators` - 获取指标列表
- `GET /api/indicators/{id}` - 获取单个指标
- `PUT /api/indicators/{id}` - 更新指标
- `DELETE /api/indicators/{id}` - 删除指标

#### 数据处理
- `POST /api/process/aggregate` - 数据聚合
- `POST /api/process/transform` - 数据转换
- `POST /api/process/validate` - 数据验证

#### 图表渲染
- `POST /api/charts/render` - 渲染图表
- `GET /api/charts/config/{type}` - 获取图表配置
- `POST /api/charts/export` - 导出图表

#### 仪表盘管理
- `POST /api/dashboards` - 创建仪表盘
- `GET /api/dashboards` - 获取仪表盘列表
- `GET /api/dashboards/{id}` - 获取仪表盘
- `PUT /api/dashboards/{id}` - 更新仪表盘
- `DELETE /api/dashboards/{id}` - 删除仪表盘
