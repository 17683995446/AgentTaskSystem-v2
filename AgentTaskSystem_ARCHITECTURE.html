🤖 AgentTaskSystem 系统架构

严格遵循二叉树架构规范 V2.0
AgentTaskSystem
Level 0 - Root
▼
TaskCore
Level 1 - Data Layer
AgentRuntime
Level 1 - Execution Layer
▼
TaskDefine
任务定义/数据模型
TaskState
状态管理/快照
TaskSchedule
队列管理/调度
TaskRunner
执行引擎/续跑
📋 任务执行流程
1
用户创建任务 → ITaskDefine.create_task()
2
初始状态 → PENDING（通过 TaskState）
3
进入队列 → TaskSchedule.enqueue()
4
执行任务 → TaskRunner.start() → 状态变为 RUNNING
5
结果 → COMPLETED（成功）或 FAILED（失败+重试）
📐 四大顶层不变公理
🌳
模块结构公理
非叶子模块固定2个子模块
🔒
调用隔离公理
跨模块只访问 Interface
📁
文件命名公理
文件名单词数 = 层级
🔢
方法行数公理
所有方法 ≤ 10 行
📄 关键接口和文件
1. TaskCore (数据层)
  • Interface ITaskDefine.py - 任务定义接口
  • Interface TaskStatusEnum.py - 任务状态枚举
  • Interface ITaskState.py - 状态管理接口
  • Impl TaskDefineImpl.py - 任务定义实现
  • Impl TaskStateImpl.py - 状态管理实现
2. AgentRuntime (执行层)
  • Interface ITaskSchedule.py - 调度接口
  • Interface ITaskRunner.py - 执行接口
  • Impl TaskScheduleImpl.py - 调度实现
  • Impl TaskRunnerImpl.py - 执行实现
